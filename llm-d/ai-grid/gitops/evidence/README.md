# Recorded evidence

Results are grouped by the date they were collected into the canonical inventory.
The `checkedAt` field inside each record is authoritative for when a check ran; some
records were moved here from older lab paths. Historical JSON references retain their
original provenance. Current inventories point to the relocated files.

These files are never Argo desired state. In particular, `2026-10-15/manual-canary-inputs.yaml`
contains retired workaround inputs and must not be applied to the current gateways.
